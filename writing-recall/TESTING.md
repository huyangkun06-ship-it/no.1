# 验证记录

## 内容

- 原 PDF 16 页，题库 83 个连续编号，249 组中英文。
- 全部标题、中英文、短语与所属 Topic 的原文执行逐项覆盖校验；核对跨页衔接和原标号异常。
- 校验两处包含 A/B 的中文短语标签不会泄漏到英文短语提示中。
- 分类：A 8、B 18、C 20、D 28、其他逻辑 9。

## Chromium 自动化实际通过

- 顺序走完 83 题并循环，切题后提示全部隐藏。
- 随机完整 83 题不重复，结束显示本轮完成；返回末题与开启新轮。
- 自定义 21–25 范围仅出现范围内的 5 题，返回沿原队列，刷新恢复队列与位置。
- 顺序/随机切换时位置独立保存。
- 编号跳转、目录标题搜索与选择。
- 四种提示独立开关、逐句揭晓、一次显示全部、再次隐藏。
- 添加和移除稍后再背、空列表、列表内随机抽背、移除当前题并刷新恢复。
- 数字与空格快捷键，输入框内不触发。
- 390×844、768×1024、1280×800 布局，展开全部提示后无横向溢出；查看手机截图。
- Service Worker 就绪后，模拟断网刷新并继续切题。
- 损坏 localStorage 和浏览器禁止存储时均仍可使用。
- 无页面 JavaScript 异常。

## 验证边界

当前环境没有华为平板、安卓实体设备或 iPad Safari，因此不能声称通过这些设备的实机兼容测试。页面采用系统字体、普通 DOM/CSS、触摸事件与原生存储，无实验性 Safari 功能。

独立 HTML 的题库、CSS、JS 已检查全部内嵌；当前托管浏览器策略禁止 `file://` 导航，因此直接从磁盘打开的浏览器验证未执行。网站地址的离线缓存与断网刷新已实际验证。

线上 GitHub Pages 发布后，还需核对部署任务成功和网站实际加载。
