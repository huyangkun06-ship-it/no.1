# 智能复习调度

仅修改 water838 应用壳、评分与备份恢复；题库文件、ID、题目与答案未修改。无可靠的同知识点关联，故不自动合并题目。

## 数据与迁移

继续使用 `yanxicang_838_water_v1`。升级前原始 JSON 保存在 `.before-smart-review` 键，设置可下载。迁移只增加 `schedule` 和顶层设置，不改历史或原到期日。旧历史无法区分新背和正式复习时，记为 `legacyCount`，不伪造正式复习次数。已有首条历史时间用于今日新背统计。`next` 是兼容字段，与 `schedule.originalDue` 同步；`lastScheduledDay` 和顶层 `reviewPlan` 单独表示实际安排。

每次真实评分追加历史，包含评价、实际时间、评分前到期日、计划间隔、耗时和操作类型。同日重复保留真实操作，但不增长连续成功次数、不创建独立到期任务。独立完整至少连续两天成功且历史遗忘率足够低才算新算法掌握。旧 master 字段迁移保留至下次评分。

JSON 导出全部顶层设置、队列与题目字段；导入完整备份不裁剪内容，并保留现有学习历史、较新的调度，导入前另存 `.before-import` 快照。导入旧备份到有新进度的设备不会回滚新进度；空设备恢复可精确重现。

## 归一化与容量

时区统一为 UTC+8 日历日。有效历史评价0～3：

- 遗忘频率 F = (评价≤1次数 + 1) / (有效评价次数 + 2)。
- 历史薄弱度 W = (Σ((3-grade)/3) + 1) / (有效次数 + 2)。
- 时间比例 T = clamp(距上次评分日数 / (2×计划间隔), 0, 1)。
- 风险 R = 0.6W + 0.4T。
- 逾期 D = clamp(逾期天数 / 14, 0, 1)。
- 重要性 I = clamp((已有importance-1)/2, 0, 1)，缺失为0.5；不分析题目内容。
- 总分 = 0.45R + 0.25D + 0.20I + 0.10F。

按当天正式复习实际耗时（未知则预计耗时）扣除预算，余量除预计每题秒数向下取整；每次切题重新限制余量。耗时以0.1新样本的EWMA逐步调整；隐藏页面后重启计时，单次样本限制1～600秒，估算范围10～600秒。用户可随时停止或主动进入预算外队列。

12.5%名额向下取整用于最久未回忆的到期题；剩余优先保护逾期≥14天题，按原始到期日先后，其后按总分，最后按ID稳定排序。保护和抽查均占预算内名额，不推迟未选中题。持续新增逾期题也不会排在保护队列中更早到期题之前。若积压长期超过处理能力，不承诺有限最长等待天数。
