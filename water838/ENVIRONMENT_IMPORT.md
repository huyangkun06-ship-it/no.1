## 本地复现

```sh
node .github/scripts/water838-build.cjs
node .github/scripts/water838-environment-validate.cjs
LOCAL_CHROME=/usr/bin/chromium PAGE_URL=http://localhost:8000/no.1/water838/ node .github/scripts/water838-environment-check.cjs
```

重新提取时需要Python的PyMuPDF、Pillow，以及带chi_sim与eng语言的Tesseract。把两份PDF放入 `work/input/`（不需提交），执行：

```sh
python water838/scripts/extract_environment.py --original work/input/环境学导论.pdf --changes work/input/环导变动.pdf --work work/environment
python water838/scripts/build_environment.py --original work/input/环境学导论.pdf --changes work/input/环导变动.pdf --work work/environment
```

使用自定义Tesseract语言目录时追加 `--tessdata /path/to/tessdata`。工作缓存不纳入生产。脚本不根据任务示例生成内容；变更资料缺失正文时应补充原PDF后再处理。
