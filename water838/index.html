录入原题

导入题库与进度备份

保留原水控211题，并加入环境学导论知识点、独立课后习题和新版补充。新版主背诵默认隐藏已删除或替换的旧内容，可切换版本查看。图片、公式及表格请展开答案中的对应原文核对；具体待核对项随题标注。JSON完整备份保留所有字段与学习记录。

导入 JSON / CSV

JSON 可为题目数组或本网页的完整备份。CSV 列名支持：chapter,type,question,answer,topic,source,hint,verified；也支持中文列名。

保存与迁移

进度保存在当前浏览器本地。Safari 清除网站数据、无痕模式或换设备可能导致丢失。建议每周导出 JSON 备份。

题库格式示例

[{"chapter":"第九章 污水水质和污水出路", "type":"简答题", "question":"这里填写已核对的原题", "answer":"这里填写已核对的答案", "topic":"水质指标", "source":"课后习题/PDF页码", "verified":false}]

对照原 PDF

选择本机 PDF 后，在本页面对照查看、手动录入；PDF 不会上传服务器，也不会自动转成已核对题目。

部分 iPad Safari 对超大 PDF 的内嵌预览支持有限，必要时可在设备自带的「文件」应用打开原 PDF。
