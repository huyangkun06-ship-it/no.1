# 838 知识体系交付说明

本次为现有原生 HTML/CSS/JavaScript 站点增加独立模块，不重构原背诵系统。入口：`water838/knowledge/`；原站导航增加“知识体系”。未发布正式网站。

## 已实现

- 环导默认采用类似 XMind 的中心主题、左右分支、彩色曲线导图。各节点单独展开/收起，支持全展开/全收起、深度控制、缩放、鼠标拖动及触屏双向滑动；标题打开正文。
- 两科共享一套规范化节点、正文组件和递归展开状态。保留独立交互知识树、正文搜索、祖先展开、定位、键盘操作、分支操作、自选范围和状态恢复。
- 4470个节点仅渲染视窗附近的目录行/导图节点；完整正文另存，不在全部展开时重复渲染。
- 共用三级抽背：题目、独立显示/隐藏框架、独立显示/隐藏完整答案。范围支持知识点、小节、章节、科目、自选、两科全部；支持上一题/下一题/随机/回到目录/阅读。
- 水控详细正文、SVG工艺流程、原生HTML对比表格、离线本地KaTeX公式及参数、单位、条件说明。
- 12组对比直接引用知识点字段；关联跳转可返回上一阅读位置。
- 手机目录抽屉、平板双栏、桌面目录拖宽、专注阅读、来源原文裁图、结构化知识导出、可搜索分页覆盖报告及完整JSON下载。
- 复用原Service Worker，缓存两科知识树和文字、公式组件与字体；原图首次查看后缓存。

## 预览和使用

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 0.0.0.0
```

本机打开 `http://localhost:8765/water838/knowledge/`。华为平板/手机与电脑在同一局域网时，把localhost替换为电脑的局域网IP。原站入口为 `http://localhost:8765/water838/`。

环导选择“思维导图”，点分支端的加减号控制展开，手指滑动浏览，点标题读正文；“闭卷抽背”分别控制提示和答案。水控选择知识树、详细电子教材或工艺对比；表格可左右滑动。静态离线缓存需要HTTPS或localhost；普通局域网HTTP仍可在线阅读，浏览器可能不允许Service Worker。
